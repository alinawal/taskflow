## 2. Development process

The project was developed following a structured workflow:

- **Planning:** Project requirements defined in `01-project-brief.md`
- **Development:** Code written following SOLID principles and layered architecture
- **Testing:** Unit, integration, and frontend tests automated
- **Deployment:** Docker containers with CI/CD pipelines
- **Documentation:** Complete set in `docs/` folder
